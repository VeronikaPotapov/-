# Финансовый ассистент проекта

Локальный MVP-прототип для проверки Excel-выгрузки бюджета ЦУП: карточка проекта, сводка по плановым и фактическим актам/поступлениям, таблицы документов и базовые замечания ассистента.

## Как запустить

Откройте `index.html` в браузере и загрузите обезличенный Excel-файл бюджета.

Прототип использует SheetJS через CDN для чтения Excel. Сам файл обрабатывается на стороне браузера и не отправляется на сервер.

## Что поддержано в первой версии

- чтение листов «Проект», «Плановые документы», «Фактические документы»;
- фильтрация статей бюджета `3.*` и `2.*`;
- карточка проекта;
- сводка по количеству, суммам и последним датам фактических документов;
- таблицы плановых и фактических документов;
- замечания по пустым датам, нулевым суммам и неполному распределению плановых документов.
- первый блок рисков по поступлениям, которые запланированы раньше или в дату ближайшего акта по той же стадии.

Комментарии к документам отображаются для контекста, но в первой риск-логике не используются как надежный ключ сопоставления.
